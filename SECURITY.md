# Security policy

Use only on systems and source code you are authorized to assess. This initial release
is intended for controlled labs and evaluation; it has not had an independent audit.
Read docs/ARCHITECTURE.md and docs/CAPABILITIES.md before relying on its boundaries.

Do not publish credentials, source code or target evidence in public issues. When
publishing your fork, enable GitHub private vulnerability reporting and use that
repository's Security tab for confidential reports. No public reporting address is
invented here. Reports should include version, a minimal synthetic reproduction,
impact and relevant environment details.

No automatic dependency/tool installation or update occurs during an assessment.
No active exploits, password guessing, persistence, shells, financial transactions,
external callbacks or intentional real-data exfiltration are supported.
